## 📌 About

This repository documents my structured, hands-on learning journey across the entire machine learning and AI lifecycle—progressing from core Python programming and exploratory data analysis to deep learning, NLP, MLOps, cloud infrastructure, and deployment.

It serves as a centralized portfolio containing practical **notebooks**, algorithmic **implementations**, concise **notes**, iterative **experiments**, and production-grade **projects**.

---

## 🗺️ Learning Roadmap

| Stage | Phase | Core Focus Areas |
| :---: | :--- | :--- |
| **01** | **Python & Data** | Python fundamentals, NumPy array computing, Pandas manipulation |
| **02** | **Statistics & EDA** | Descriptive & inferential statistics, probability, exploratory analysis, feature engineering |
| **03** | **Machine Learning** | Supervised & unsupervised learning: regression, classification, clustering, ensemble methods |
| **04** | **Deep Learning & NLP** | Neural architectures (ANN, CNN, RNN, LSTM, GRU), word embeddings, attention, transformers |
| **05** | **MLOps Lifecycle** | Experiment tracking (MLflow), dataset versioning (DVC, DagsHub), containerization (Docker), CI/CD |
| **06** | **Cloud & Deployment** | Microservice APIs (Flask, BentoML), interactive apps (Streamlit), cloud services (AWS, Azure) |
